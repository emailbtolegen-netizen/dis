## 5. Правила импорта

1. Формат листа определяется по заголовкам (МЖД, перечень энергообъектов, таблица КСК); для других файлов — ручное сопоставление столбцов.
2. Каждая строка получает **ключ сопоставления**: МЖД — нормализованный адрес; энергообъекты — раздел + класс напряжения + наименование; КСК — год + адрес. При повторе ключа в файле добавляется `#2`, `#3` — записи **не объединяются**, а помечаются как возможные дубликаты.
3. При повторной загрузке: новые ключи → «новые», совпавшие с отличиями → «изменённые» (с перечнем полей), совпавшие без отличий → «без изменений», объекты прошлых импортов этого формата, которых нет в файле, → «отсутствуют в файле» (не удаляются).
4. Записи, изменённые вручную после импорта, по умолчанию не перезаписываются.
5. Перед применением — резервная копия базы; применённый импорт можно откатить.
6. Исходные значения сохраняются без изменений; нормализованные значения (числа, мощность, номер ТП, класс напряжения) хранятся отдельно с пометкой «рассчитано».
7. Отсутствующие сведения не заполняются: поле остаётся пустым и отображается как «Не указано».

## 6. Дополнение: файл «Лифты города Атырау 2022-1.xlsx»

Один лист «лифты г.Атырау», 214 строк с домами + строка «Всего». Столбцы: № · Адрес дома · Состояние лифтов · Примечание · Кол-во этажей · Кол-во подъездов · Общее кол-во лифтов · Пассажирских · Грузопассажирских · Лифты в нерабочем состоянии (всего / пассажирские / грузопассажирские) · Орган управления объектом кондоминиума · Организация, обслуживающая лифты.

**Как перенесено.** Категория «Лифты МЖД» в разделе «Жилищный фонд»: одна запись = одна строка файла (сведения о лифтах дома). Данных по каждому лифту отдельно (заводские номера, годы установки, сроки эксплуатации) в файле нет — отдельные лифты не создавались. Записи связаны с карточками МЖД (связь «Лифты этого дома МЖД»), в карточке дома — вкладка «Лифты». Исходный текст «Состояние лифтов» и «Примечание» сохранён без изменений; дополнительно рассчитаны: обобщённое состояние (для фильтра), признаки «Требует внимания» (кап. ремонт, модернизация с ПСД, срок эксплуатации, демонтаж — по исходным формулировкам), год модернизации из текста «модернизация в 2013 году», наличие пандуса. Столбцы организаций содержат ФИО и телефоны — сохранены как конфиденциальные; название организации выделено в отдельное поле.

**Сверка.** Итог «Всего» (712 лифтов: 656 пассажирских, 54 грузопассажирских; 42 нерабочих: 40 + 2) совпадает с суммой импортированных строк по всем шести столбцам.

**Особенности файла:**
- пропущен № 198 (последний № 215 при 214 строках);
- строки 175–215 — по составу более поздний перечень от обслуживающих организаций; в «Примечании» там указан только год (2005–2025) без пояснения — сохранён как есть;
- 12 домов встречаются в файле дважды (например, «Молдагалиева, 5»: «не работает, требуется кап.ремонт» и «работают, 2024»), поэтому итог «Всего» учитывает часть лифтов повторно; записи не объединены;
- в 7 строках перечислено несколько домов («Момышулы 23,35,27», «Амандосова 42/2, 42», «Акшағала 2, строение 9 (6 домов, 11 блоков)» и др.) — автоматически не привязываются;
- 4 строки без описания состояния.

**Привязка к МЖД** (новые карточки МЖД не создаются): по точному адресу — 153 записи; после очистки адреса (названия ЖК, инициалы, «Уалиханова/Валиханова», «Абилхайр хан/Абулхаирхана», «Сарыарка/Сары-Арка») — 19; дом ↔ его блоки (связь со всеми блоками) — 3; итого 175 из 214. Остальные 39 (новостройки ЖК, строки с несколькими домами, адреса, отсутствующие в реестре МЖД) — в «Качество данных → Нет связи со связанным реестром». Связи по очищенному адресу и по блокам имеют достоверность 75 % / 50 % и требуют подтверждения. Дополнительно сверяется количество лифтов с реестром МЖД («Расхождения между файлами»).

## 9. Дополнение: таблица «АВАР 88 үй.xlsx» (лист «тізім»)

- Тот же перечень из 88 домов, что и на карте аварийных домов: номера по списку, адреса и координаты совпадают с данными карты.
